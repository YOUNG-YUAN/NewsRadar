# NewsRadar (AI 新闻雷达)
NewsRadar 是一款基于 Python 开发的自动化信息聚合与分析工具。系统通过多线程请求 RSS 订阅源，调用大语言模型（LLM）进行文本分析，并生成 Markdown 或 PDF 格式的结构化简报。
当前版本（v2.2.3）主要优化了并发抓取机制、本地数据持久化逻辑及界面的动态交互控制，以提高系统的稳定性和数据处理效率。

---

## 核心功能与机制说明

### 1. 并发抓取与网络控制

- **多线程获取**：系统采用 `ThreadPoolExecutor` 模块，最高支持 20 线程并发处理 RSS 数据源请求，降低总体等待时间。
- **独立结果日志**：单条数据源抓取完成后，系统将输出独立的统计日志，显示该源截获的有效新资讯数量。
- **网络代理隔离**：RSS 订阅源的请求代理与 LLM API 调用的网络代理在配置与运行层面完全解绑。
- **错误重试机制**：网络请求、JSON 文本解析及文件读写环节均内置了标准 3 次重试（3-Retry）逻辑。

### 2. AI 分析与输出约束

- **异构节点并发**：支持配置多个不同服务商、模型名称及 Base URL 的 API 节点。系统自动将获取到的新闻列表切分为任务单元，分配至各个节点并行处理。
- **严格 JSON 约束**：提示词工程中加入了格式要求模板，强制 LLM 按预设 JSON 数组格式（包含来源、时间、链接等必填字段）返回数据，以降低大模型输出幻觉引发的解析异常率。
- **轮次账单统计**：每个“监听-分析”轮次结束后，系统自动汇总并输出日志，包含当次截获总条目、更新日报数量以及累加计算的 Token 总消耗量。

### 3. 数据持久化与周期报表

- **JSON 数据持久化**：系统废弃内存字典存储方式，将新截获并分析完毕的数据按发布日期归档，以 `daily_YYYY-MM-DD.json` 格式持久化至本地 `data/database/` 目录。
- **报告渲染机制**：系统检测到某日新增数据后，会读取对应的 JSON 文件重新渲染当日的 PDF/Markdown 日报。如果存在数据补签情况，系统日志将进行提示并静默覆盖旧文件。
- **手动触发时序报表**：历史周报与月报的合并生成逻辑不再依赖后台自动巡检。用户需在界面手动点击“立刻扫描并合并周期报告”按钮触发。
  - **触发条件限制**：周报限定在次周一 16:00 之后允许生成；月报限定在次月 5 日 08:00 之后允许生成。未满足时间阈值的报表将被系统跳过合并。

### 4. 界面交互 (GUI) 与状态管理

- **动态配置应用**：在任务执行中途触发“暂停”操作后，界面的参数设置面板将被唤出。用户可修改 AI 模型参数、保存路径或监听设置，修改内容在点击“恢复获取”后立即对后续任务生效，无需重启程序。
- **长按防误触中止**：程序的“中止”操作采用时间监听机制。持续按下指定按钮 4 秒方可触发中止信号，以防误操作中断正在进行的网络请求或文件写入。
- **所见即所得排版**：提供排版预览界面，支持对各类文本元素（标题、摘要、关键词等）分配不同的本地字体。支持读取 TTF/TTC 格式字体并识别其字重参数。

## 安装与配置说明

### 1. 运行环境配置
建议在 Python 虚拟环境中运行本项目：

```bash
# 克隆仓库
git clone https://github.com/YourUsername/NewsRadar.git
cd NewsRadar

# 安装依赖
pip install -r requirements.txt

```

### 2. 外部字体文件配置
受开源版权限制，仓库内不提供商业字体文件。
配置路径：

1. 打开项目根目录下的 `fonts/` 文件夹。
2. 复制系统中合规的字体文件（如 `.ttf`, `.ttc`）至该目录下。
3. 运行程序后，在 [个性化] 界面选择对应字体以应用。

### 3. 程序启动

```bash
python main.py

```
